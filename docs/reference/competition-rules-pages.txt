Description # 🛡️ Multilingual Prompt-Attack Classification

Your job is simple: **fine-tune one of the provided models to sort prompts into 3 classes.**

Portuguese, French, and Italian are **high-resource languages** for general NLP, but **low-resource for AI safety**. Most prompt injection and guardrail datasets are built for English. In this challenge, your goal is to bridge this gap and detect non-English prompt injection attacks. The dataset contains prompts written in **Portuguese, French, Italian and English** — most of them **not in English**, which is exactly where LLM safety filters tend to break.

| label | meaning |
|---|---|
| `BENIGN` | a normal, safe user request |
| `JAILBREAK` | an attempt to talk the model out of its safety rules |
| `PROMPT_INJECTION` | an attempt to hijack the model's instructions |

**What you do:**
1. Pick a model from the approved model list.
2. Fine-tune it on `train.csv`.
3. Predict a label for every row in `test.csv`.
4. Submit your `id,label` CSV to the leaderboard.

**Why it matters:** safety filters trained on English miss attacks written in other languages. Build one that doesn't.

#### Step 2 — Fine-tune it

Train on `train.csv` (14,000 rows, columns `id, text, language, label`) and predict on `test.csv` (6,000 rows).

⚠️ The classes are **imbalanced** — `BENIGN` 62%, `JAILBREAK` 31%, `PROMPT_INJECTION` 7%. Predicting everything as `BENIGN` will score badly on the metric. Plan for that.

**Suggested directions:**
* Encoder route: Hugging Face `AutoModelForSequenceClassification` with `num_labels=3`.
* LLM route: LoRA / QLoRA fine-tuning, or a constrained classification head.
* Handle imbalance with class weights, focal loss, or resampling.
* Use the `language` column — per-language performance is not uniform.
* Focus on **robust generalisation**, not leaderboard overfitting.

Evaluation ### 🔹 Challenge — Multilingual Prompt-Attack Classification

This is a **3-class classification task**: given a text prompt, predict whether it is `BENIGN`, `JAILBREAK`, or `PROMPT_INJECTION`.

#### **Metric**

Submissions are evaluated using the **macro-averaged F1 score**.

* F1 is computed **separately for each of the 3 classes**, then averaged with **equal weight**.
* This means the rare `PROMPT_INJECTION` class (7% of training data) counts **just as much** as `BENIGN` (62%).
* Submitting all `BENIGN` scores roughly `0.26`. A perfect submission scores `1.0`.

#### **Submission Format**

Your submission file must be a CSV with the following columns:

* `id` — unique identifier for each test prompt
* `label` — predicted class, exactly one of `BENIGN`, `JAILBREAK`, `PROMPT_INJECTION`

The file must contain **exactly 6,000 rows plus a header**, one for every `id` in `test.csv`.

**Example:**
